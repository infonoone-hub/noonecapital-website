Your AI Intake Address
Gmail
  1. Open Gmail → gear icon → See all settings
  2. Go to Forwarding and POP/IMAP tab
  3. Click Add a forwarding address → paste intake address above
  4. Click the confirmation link Gmail sends to that address
  5. Back in settings, select Forward a copy of incoming mail
  6. Click Save Changes
Outlook / Microsoft 365
  1. Settings → View all Outlook settings
  2. Mail → Forwarding
  3. Toggle Enable forwarding on
  4. Paste intake address → Save
Tip: You can forward multiple inboxes (info@, maintenance@, rentals@) to the same intake address.

How to Forward Your Calls

Set up call forwarding on your existing business number so the AI answers when you can't. You can forward all calls or just unanswered ones.

AT&T
Forward all: dial *21* + AI number + #
Forward unanswered: dial *61* + AI number + #
Verizon
Forward all: dial *72 + AI number, press Call
Forward unanswered: dial *71 + AI number, press Call
T-Mobile
Forward all: dial **21* + AI number + #
Forward unanswered: dial **61* + AI number + #
Google Voice / VoIP
Go to Settings → Calls → Call Forwarding and add your AI receptionist number.
Recommended: Use "forward unanswered calls" so you can still pick up when you're available — AI only kicks in when you don't answer.
